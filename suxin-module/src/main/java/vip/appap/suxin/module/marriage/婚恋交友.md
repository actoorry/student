# 婚恋交友平台方案

> 面向**本人自主择偶**的婚恋交友与撮合服务；入驻商家、红娘机构使用平台系统完成获客、服务与结算。本文档为产品需求概要，与《婚恋交友-数据库设计》配套迭代。

---

## 一、建设范围与产品定位

### 1.1 系统概述

建设一套婚恋交友与撮合服务平台，服务于**实名认证的 C 端用户**、入驻商家/红娘机构及平台运营方，实现资料展示与推荐、意向互动、私信与活动、会员与订单、**分销推广与提成结算**、内容运营及风控审核等功能。

### 1.2 核心定位

- 打造高效、安全、有温度的**本人自主择偶**服务。
- 为入驻商家提供：资源汇聚、撮合效率提升、收益与结算清晰的可配置 SaaS 能力。
- 通过**平台分销员**与**邀请得聊天券**两类推广机制扩大获客，并与商家自建分销比例协同。

### 1.3 交付终端

| 终端             | 说明 |
|----------------|------|
| 用户端小程序 / H5 / app | 微信生态裂变、支付、模板消息 |
| 红娘端 / 工作台      | 线索跟进、订单与提成 |
| 商家端 PC /       | 机构管理、服务配置、**分销比例**、结算 |
| 平台管理端 PC       | 运营、审核、分销与财务、风控 |

### 1.4 使用角色

| 角色    | 说明 |
|-------|------|
| 用户    | 本人注册择偶；完成实名认证后方可使用核心功能 |
| 分销员   | 由平台审核开通；通过专属链接带来注册用户，从其后续消费中获得提成 |
| 红娘    | 机构或平台签约红娘，跟进线索与订单 |
| 商家    | 婚恋机构 / 工作室，管理红娘、服务与**本机构分销比例** |
| 平台    | 配置、审核、风控、财务与全局分销规则 |

### 1.5 平台收益来源（概要）

- 商户软件使用费、可选经营陪跑服务费。
- C 端个人会员费及增值服务（与商家分成规则可配置）。
- 合作方广告或导流分成。
- 分销体系中的平台抽成或服务费（与结算规则一并配置）。

### 1.6 生态扩展（可选）

- **学习成长**：形象礼仪、沟通表达等课程合作。
- **旅行社交**：短途/主题游与线下联谊活动结合。

### 2.3 邀请好友与聊天券

- **场景**：用户将平台分享给好友（海报、链接、小程序码等），好友通过**带邀请人标识**的入口完成注册并实名通过后，邀请人获得奖励。
- **奖励**：**聊天券** × N（张数由平台配置，默认 1 张/有效邀请）。
- **聊天券规则**：
  - 每张聊天券可免费与**一名指定对象**建立**一次**沟通（开启一个会话或发送首条私信/红娘中转会话，产品择一统一）。
  - 使用后核销；过期规则（如 90 天）由平台配置。
  - 不可提现、不可转赠（防刷）。
- **有效邀请判定**：被邀请人完成注册 + 实名认证通过 + 非同一设备/同一证件重复注册；异常邀请平台可作废奖励。
- **与分销区别**：邀请聊天券为**平台拉新激励**；分销提成为**消费分成**，二者邀请码/链接参数分离，避免重复计费。

### 2.4 分销体系（平台 + 商家）

#### 2.4.1 分销员

- 平台侧开放**分销员注册/申请**，经平台审核通过后成为分销员。
- 分销员获得**专属推广链接/码**（含 `distributor_partner_id` 等追踪参数）。
- 用户通过该链接**首次注册**时，与该分销员建立**绑定关系**（终身或按配置有效期，默认注册后永久绑定首单分销员）。

#### 2.4.2 提成范围

- 被绑定用户在其绑定关系有效期内产生的**可分销订单**实付金额，按规则计算分销员提成。
- 可分销订单类型（可配置）：个人会员费、活动报名费、陪跑服务费、商家套餐等；退款订单冲减提成。

#### 2.4.3 商家分销比例

- **商家**在商家端为**本机构名下商品/套餐**设置分销提成比例（如会员套餐的 X%、活动费的 Y%）。
- 平台可设置**比例上下限**与默认比例；未单独配置的 SKU 走平台默认。
- 单笔订单提成 = 实付金额 × 生效比例；若同时存在平台分销员与商家规则，以产品定稿的**优先级**为准（建议：分销员绑定只影响「谁拿分销员提成」，商家比例决定「从哪笔服务费里出」）。

#### 2.4.4 结算与风控

- 提成进入分销员**可提现余额**或账期结算（T+N）；平台端对账、提现审核。
- 防作弊：自买自推、循环注册、异常退款、同一证件多号等规则拦截。
- 分销员端（可在用户端「我的」内嵌或独立入口）：推广数据、绑定人数、订单与提成明细、提现。

## 三、用户端功能需求

### 3.1 启动与品牌

- 启动页寄语、品牌图标与 Slogan。

### 3.2 注册、登录与实名

- 手机号注册 / 微信授权注册（须绑定手机）。
- 登录：验证码、密码、微信；登录后若未实名，全局引导至认证流程。
- **实名认证**：身份证信息、人脸核验、可选学历/视频认证；进度与结果页。
- 账号注销与数据导出（合规）。

### 3.3 推荐与发现

- **推荐流**：今日推荐、榜单运营位、会员卡片（照片、基础信息、距离、简介、动态摘要）。
- **检索**：地域、年龄、学历、职业等可配置维度（仅认证用户）。
- **互动线索**：谁看过我；关注 / 关注我的 / 互相关注（见 §2.2）。
- **关注**：我关注的 / 关注我的。
- 附近会员、在线会员（可选，需位置授权）。

### 3.4 意向与会员

- **关注**：对目标用户点关注 → 触发 §2.2 即时通知。
- **会员权益**：查看完整资料、交换联系方式（如微信）、打招呼次数、置顶等（初级/高级可配置）。
- **聊天券**：我的聊天券列表、使用记录；邀请好友入口与规则说明。

### 3.5 消息

- 会员私信、红娘消息、系统消息、通知公告。
- **系统通知类型**：关注提醒、互相关注、谁看过我、活动提醒、认证结果、聊天券到账、分销提成到账等。

### 3.6 活动（含相亲角）

- **导航约定**：相亲角与线上/线下活动同属「活动」一级入口。
- **线上**：话题、线上课堂/分享、视频见面等。
- **线下**：相亲会、茶话会、主题联谊会等。
- **相亲角**：平台介绍、红娘寄语、喜讯、干货/公众号引导等。
- **旅行出游**（可选）：与商家或第三方线路结合。

### 3.7 我的

- 资料与隐私、相册、择偶要求、完善度。
- 认证中心、会员服务、我的红娘（选择/联系/更换）。
- **邀请好友**：生成分享素材，查看邀请记录与聊天券奖励。
- **分销中心**（若为分销员）：推广链接、业绩与提现。
- 联系红娘、设置、客服。

### 3.8 平台对接

- 公众号（模板消息、菜单、授权）。
- 视频号（引流、直播预约）。
- 微信支付（会员、活动、增值服务）。

## 四、红娘端

- **线索管理**：分配、跟进记录、标签（意向强度、约见状态）。
- **用户视图**：查看授权范围内资料与沟通记录（对象为 C 端 `partner`，无家长代操作视图）。
- **任务与提醒**：待回访、待约见、会员到期；**关注/互相关注**可生成跟进任务（可配置）。
- **订单与提成**：套餐、活动、陪跑服务单（与商家结算规则对齐）。
- **内容工具**：活动海报、话术模板（需审核）。

## 五、商家端

### 5.1 商家类型

- 个人工作室、公司制婚恋机构。

### 5.2 对客服务配置

- 会员推荐服务、恋爱陪跑、线下活动发布与报名管理。

### 5.3 收益与分成

- 个人会员费分成、活动费用、推荐服务费、陪跑服务费、活动报名费。

### 5.4 分销配置（商家）

- 为本机构**会员套餐、活动、陪跑产品**等设置**分销提成比例**（受平台上下限约束）。
- 查看经由分销带来的订单明细与应付提成（与平台结算对账）。

## 六、平台端（管理后台）

- **用户与内容**：实名与认证审核、动态/相亲角审核、举报与风控。
- **商家与红娘**：入驻审核、资质、红娘账号与权限、机构分成比例。
- **运营配置**：推荐权重、Banner、榜单、会员套餐与价格。
- **分销管理**：分销员审核、全局默认比例、比例上下限、绑定规则、提成与提现审核、作弊处置。
- **邀请活动**：聊天券发放规则、有效邀请判定、防刷策略。
- **数据与财务**：订单流水、分销对账、结算周期、发票信息。
- **安全合规**：日志审计、敏感词、用户协议与隐私政策。

## 七、跨端核心路径

| 角色 | 核心路径 |
|------|----------|
| C 端用户 | 注册 → **实名认证** → 浏览推荐 → 关注（即时通知对方）→ 私信/活动 → 会员增值 |
| C 端推广 | 分享邀请 → 好友注册实名 → 得聊天券；或申请分销员 → 推广链接 → 绑定用户消费 → 提成 |
| 商家/红娘 | 获客 → 配置分销比例 → 服务交付 → 结算 |
| 平台 | 审核认证与分销员 → 运营配置 → 对账与风控 |
