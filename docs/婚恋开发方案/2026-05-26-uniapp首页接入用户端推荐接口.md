# uniapp 首页接入用户端推荐接口

## 本次完成

已将 `UI/uniapp-marriage/pages/index/index.uvue` 首页从本地 mock 数据切换为调用用户端接口：

- `GET /app-api/marriage/recommend-member/page`

对应后端控制器：

- `vip.appap.suxin.module.marriage.controller.app.AppPartnerDatingProfileController`

## 改动内容

首页原先直接引用：

- `data/mock-data.uts` 中的 `recommendMembers`

现已改为：

1. 页面 `onLoad` 时请求后端推荐分页接口
2. 使用接口返回的 `list` 填充首页推荐卡片
3. 保留左右滑动切换逻辑
4. 当本地列表滑到末尾且后端还有更多数据时，自动继续加载下一页
5. 增加加载态、空态、失败重试

## 前端接入细节

当前首页请求地址写死为：

```text
http://localhost:48080/app-api/marriage/recommend-member/page
```

并且会优先从本地缓存读取：

- `accessToken`
- `token`

读取到后自动带上：

```text
Authorization: Bearer {token}
```

## 当前限制

这次只接了首页推荐列表。

还没有接：

- 满意接口
- Hi 打招呼接口

因此首页两个浮动按钮目前仍然只做 toast 提示。

## 风险说明

由于 `uniapp-marriage` 是 HBuilderX 的 uni-app x 工程，本次没有通过命令行独立完成编译验证，需在 HBuilderX 中重新运行页面确认。

重点验证：

1. 首页打开后是否能正常拉到推荐数据
2. 未登录时后端是否返回 401
3. 已登录后 `Authorization` 是否正确带上
4. 左右滑到最后一张时是否会继续加载下一页
