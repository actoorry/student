# 付费会员体系开发方案

## 原始需求

1. 复用 SPU + SKU 产品体系，走现有销售订单 + 支付订单流程
2. 一种会员类型，仅时长不同：1 个月、3 个月、1 年
3. 无自动续费
4. 支持退款，退款后回收会员
5. 叠加购买：累加时长

## 最小改动方案

```
partner 表 + member_expire_time          ← 1 条 DDL
product_sku 表 + duration_days            ← 1 条 DDL（让 SKU 携带时长）
ProductTypeEnum + MEMBER(4)               ← 1 行代码
支付成功回调：更新 member_expire_time       ← 10 行代码
退款回调：扣减 member_expire_time          ← 10 行代码
定时任务：到期回收                          ← 10 行代码
```

**不建新表，不复用现有的 sales_order / pay_order 查询购买记录即可。**

---

## 一、数据库改动（2 条 DDL）

```sql
-- 1. partner 加会员到期时间
ALTER TABLE `partner`
  ADD COLUMN `member_expire_time` datetime NULL DEFAULT NULL COMMENT '会员到期时间' AFTER `customer_level`;

-- 2. product_sku 加有效天数（供会员产品使用）
ALTER TABLE `product_sku`
  ADD COLUMN `duration_days` int NULL DEFAULT NULL COMMENT '有效天数（会员产品专用）';
```

### 2.2 会员激活（放在 PartnerService 里，不新建 Service）

```java
// PartnerServiceImpl.java

/**
 * 支付成功后激活/续期会员（累加时长）
 */
public void activateMember(Long partnerId, Long payOrderId) {
    // 1. 通过 payOrderId → tradeOrder → tradeOrderItem → skuId → durationDays
    TradeOrderDO order = tradeOrderService.getByPayOrderId(payOrderId);
    TradeOrderItemDO item = order.getItems().get(0); // 会员订单通常就一个 item
    ProductSkuDO sku = productSkuService.getSku(item.getSkuId());
    
    if (sku.getDurationDays() == null || sku.getDurationDays() <= 0) {
        return; // 不是会员产品，跳过
    }
    
    // 2. 累加时长
    PartnerDO partner = getPartner(partnerId);
    LocalDateTime now = LocalDateTime.now();
    LocalDateTime base = partner.getMemberExpireTime() != null 
        && partner.getMemberExpireTime().isAfter(now) 
        ? partner.getMemberExpireTime() : now;
    
    partner.setIsMember(true);
    partner.setMemberExpireTime(base.plusDays(sku.getDurationDays()));
    partnerMapper.updateById(partner);
}

/**
 * 退款后回收会员时长
 */
public void revokeMemberByRefund(Long payOrderId) {
    TradeOrderDO order = tradeOrderService.getByPayOrderId(payOrderId);
    TradeOrderItemDO item = order.getItems().get(0);
    ProductSkuDO sku = productSkuService.getSku(item.getSkuId());
    
    if (sku.getDurationDays() == null || sku.getDurationDays() <= 0) {
        return;
    }
    
    PartnerDO partner = getPartner(order.getUserId());
    if (partner.getMemberExpireTime() == null) return;
    
    LocalDateTime newExpire = partner.getMemberExpireTime().minusDays(sku.getDurationDays());
    if (newExpire.isBefore(LocalDateTime.now())) {
        partner.setIsMember(false);
        partner.setMemberExpireTime(null);
    } else {
        partner.setMemberExpireTime(newExpire);
    }
    partnerMapper.updateById(partner);
}

/**
 * 定时任务：到期回收
 */
@Scheduled(cron = "0 0 2 * * ?")
public void expireMembers() {
    List<PartnerDO> list = partnerMapper.selectList(
        new LambdaQueryWrapperX<PartnerDO>()
            .eq(PartnerDO::getIsMember, true)
            .lt(PartnerDO::getMemberExpireTime, LocalDateTime.now())
    );
    for (PartnerDO p : list) {
        p.setIsMember(false);
        partnerMapper.updateById(p);
    }
}
```

### 2.3 支付/退款回调接入

在 `PayOrderServiceImpl` 支付成功回调中加一行：

```java
// 支付成功后
partnerService.activateMember(order.getUserId(), payOrder.getId());
```

在退款成功回调中加一行：

```java
// 退款成功后
partnerService.revokeMemberByRefund(refund.getPayOrderId());
```

## 六、关键逻辑

| 场景 | 逻辑 |
|------|------|
| 首次购买 | `expire_time = now + 时长` |
| 叠加购买 | `expire_time = max(now, 现有expire_time) + 时长` |
| 到期回收 | 定时任务：`expire_time < now` → `is_member = false` |
| 退款 | `expire_time = 现有expire_time - 本次时长`，若 < now 则回收 |
