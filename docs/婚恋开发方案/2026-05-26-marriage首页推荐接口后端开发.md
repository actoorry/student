## 数据来源

本次接口基于以下表拼装：

- `partner_dating_profile`
- `dating_profile_tag`
- `dating_profile_album_image`

当前查询规则：

- 仅查询 `recommend_flag = 1`
- 仅查询 `real_verified = 1`
- 排除当前登录用户本人
- 按 `recommend_sort ASC, id DESC` 排序

## 返回字段

已按首页当前真实需要返回：

- `id`
- `name`
- `age`
- `city`
- `education`
- `job`
- `height`
- `income`
- `verifiedLabel`
- `mainImage`
- `avatarImage`
- `onlineLabel`
- `viewerLabel`
- `bio`
- `tags`
- `interestTags`
- `albumImages`

## 处理说明

- `city`：由 `live_area_id` 通过 `AreaUtils` 转中文地名，并取末级城市/地区名称
- `age`：由 `birth_date` 动态计算
- `education`、`income`：当前在 `PartnerDatingProfileServiceImpl` 中按枚举值做了本地文案映射
- `tags`：取 `dating_profile_tag` 中 `tag_type = 1/3`
- `interestTags`：拼接城市、身高、学历、收入，再追加 `tag_type = 2`
- `albumImages`：来自相册表；若无相册则回退到主图

## 当前范围
